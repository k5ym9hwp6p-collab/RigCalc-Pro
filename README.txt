RigCalc Pro Version 1.9

New — Well Control + Live Well Profile integration
- Live Well Profile can feed Well Control with current bit MD, interpolated TVD, detailed drill-string internal volume, annular volume, representative annular capacity, pump output and pump speed.
- One-button geometry sync from Well Control.
- Optional automatic geometry synchronization.
- Well Control Live card added to Live Well Profile.
- Start/reset a well-control circulation reference using the same pumped-volume counter as Circulate Live.
- Estimated influx interval is shown on the well profile and moves up the annulus as circulation volume increases.
- Kill-mud front is tracked down the detailed drill string and then up the annulus.
- Live display includes influx front/tail, formation at influx front, kill-mud phase, strokes since WC tracking started and target pump pressure.
- Casing shoe / calculated MAASP marker is overlaid on the profile.
- Driller's Method and Wait & Weight target-pressure position are reflected in the live panel.

New — Well trajectory display selector
- Deviated / Horizontal uses the entered directional survey.
- Vertical draws a straight well profile.
- Selection is remembered on the device.
- The selector changes visual layout only; entered survey TVD remains the basis for hydrostatic and pressure calculations.

Important
This well-control visualization is a planning/checking aid only. Influx movement is a simplified volumetric model and does not model gas expansion, compressibility, migration, multiphase flow, choke response, temperature effects or dynamic friction. Target pump pressure is a reference interpolation, not an operational choke instruction. Use certified well-control practices, approved operator/company procedures and kill sheets, actual rig instrumentation, and verified equipment/casing/shoe limits.
