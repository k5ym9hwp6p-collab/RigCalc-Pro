Circulate Live:
- Start / Pause / Reset live circulation tracking
- Live elapsed circulation time
- Live strokes and pumped volume
- Moving returns-front marker
- Formation currently at the returns front
- Continuously recalculated time remaining to surface
- Immediate recalculation when pump speed or pump output changes
- Saved live state on the device

The live returns-front position is a calculated annular-volume estimate. Actual transport can differ because of compressibility, cuttings loading, washout, temperature, multiphase flow, surge/swab, changing geometry, pump efficiency and instrumentation differences. Always use approved rig, MPD and well-control procedures and actual rig instrumentation.
