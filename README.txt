RigCalc Pro Beta 1.14 — Focused Live Well Profile

UPLOAD
Extract this ZIP and upload the included app files into the same existing website folder. README.txt is optional; there is no test folder. Keep website data to preserve entered values. Close/reopen and reload after uploading to see Beta 1.14.

WHAT CHANGED
- Removed Well Control Live, its tracking controls, background updates and trajectory markers.
- Removed Returns Coming, automatic formation tags and arrival history from the interface and active code.
- Retained standalone Well Control calculators, generated kill sheet and explicit Pull from profile action.
- Profile changes no longer automatically copy geometry into the standalone Well Control inputs.
- Moved trajectory settings, survey, hole intervals and string modeling into expandable Well Setup.
- Moved manual circulation inputs and their readouts under Manual bottoms-up calculator within Well Setup.
- Kept bit MD, pump output and SPM visible at the top for operation.
- Collapsed repeated loop totals under Loop totals & estimates; retained the primary location card with remaining loop volume and time.
- Collapsed capacity inspection under Capacities & volumes; tapping a band opens its details automatically.

RETAINED
Coloured string/cased/open-hole flow bands; casing shoe MD classification; live circulation with preserved displacement across rate changes; full-circulation marker and progress; sweep/pill down-string and annular tracking; zoom; active Drill String / Casing Run model selection; all other calculator screens.

Saved well geometry, string models, circulation state and existing calculator storage keys are retained. Removed feature data is not erased from device storage, but no longer creates markers or runs background calculations.

VALIDATION
JavaScript syntax, removed-element reference checks, unique HTML IDs, setup grouping and operating controls checked. All non-profile tool sections compared unchanged against Beta 1.13. Flow capacity/trajectory interaction tests and circulation rate-change/pause accounting tests passed. Full browser/device rendering has not been verified in this environment.
